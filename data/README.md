### Protein FASTA File

The protein FASTA file contains the reference amino acid sequence of the STAC3 protein obtained from NCBI. A FASTA file includes a header with information identifying the protein, followed by the sequence written using single-letter amino acid codes.

The file was used as the main input for the R analysis. The script read the sequence from the FASTA file to calculate the protein length and count how many times each of the 20 standard amino acids appeared. These results were then used to create the amino acid composition table and bar graph.

This file provides the original protein sequence used in the analysis and helps make the results reproducible.
